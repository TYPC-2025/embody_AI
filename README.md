## 1. 内容概览

如果把机械臂想成一条人的手臂，它由很多段组成：

- 肩膀、手肘、手腕，类似机器人里的关节。
- 上臂、前臂、手掌，类似机器人里的连杆。
- 手指或夹爪所在的位置，类似机器人里的末端执行器。

我们真正关心的问题通常是：

> 我已经知道每个关节转了多少度，那么机械臂末端现在在哪里？朝向哪里？

这就是正运动学要解决的问题。

这节内容的核心逻辑可以概括成一句话：

> 给机械臂的每一段建立坐标系，用 DH 参数描述相邻坐标系之间的关系，再把这些关系写成齐次变换矩阵，最后一路相乘，得到末端执行器相对于机器人基座的位姿。

也就是说，文章不是在讲“怎么控制机械臂运动起来”，而是在讲运动控制之前非常基础的一步：如何描述机械臂的几何状态。

## 2. 正运动学

正运动学，英文是 Forward Kinematics，简称 FK。

它的输入是关节变量，输出是末端执行器位姿。

更直白一点：

```text
每个关节的角度/位移  --->  末端执行器的位置和朝向
```

比如一个二维平面上的二连杆机械臂：

- 第一段长度是 L1。
- 第二段长度是 L2。
- 第一个关节转角是 theta1。
- 第二个关节转角是 theta2。

那么机械臂末端的位置可以写成：

```text
x = L1*cos(theta1) + L2*cos(theta1 + theta2)
y = L1*sin(theta1) + L2*sin(theta1 + theta2)
```

这两个公式其实非常符合直觉：

- 第一段连杆把末端从原点带到某个位置。
- 第二段连杆是在第一段已经转过去的基础上继续转。
- 所以第二段的绝对方向不是 theta2，而是 theta1 + theta2。

这就是正运动学最朴素的意思：沿着机械臂从底座往末端一步步走，把每一段贡献的位置和方向累加起来。

## 3. 末端执行器位姿

末端执行器，英文是 end-effector，指机械臂最末端真正干活的部分，例如：

- 夹爪。
- 吸盘。
- 焊枪。
- 相机。
- 手术器械。
- 机器人手掌。

位姿这个词包含两个部分：

- 位置：它在哪里。
- 姿态：它朝向哪里。

在三维空间中，位置通常是三个数：

```text
x, y, z
```

姿态则描述末端坐标系的朝向。可以用旋转矩阵、欧拉角、四元数等方式表示。DH 参数和正运动学里最常见的是用齐次变换矩阵来同时表达位置和姿态。

一个 4x4 齐次变换矩阵大概长这样：

```text
T =
[ R11 R12 R13 px ]
[ R21 R22 R23 py ]
[ R31 R32 R33 pz ]
[  0   0   0  1 ]
```

这里可以分成两块看：

- 左上角 3x3 的 `R` 是旋转矩阵，表示姿态，也就是末端执行器的朝向。
- 最右边的 `p = [px, py, pz]` 是位置，表示末端执行器相对基座坐标系在哪里。

所以所谓“求末端执行器位姿”，就是求这个矩阵 `T`。

## 4. DH 参数的作用

机械臂的每个关节和连杆都有自己的坐标系。如果机械臂有 6 个关节，你就会面对很多组坐标系之间的关系。

如果每组关系都临时手写，会很乱。DH 参数的作用就是提供一套标准化规则：

> 不管机械臂有多少个关节，我们都用同样 4 个参数描述相邻两个连杆坐标系之间的关系。

这 4 个参数分别是：

| 参数    | 常见读法 | 它描述什么                  |
| ------- | -------- | --------------------------- |
| `theta` | 关节角   | 绕上一坐标系的 z 轴转多少   |
| `d`     | 连杆偏移 | 沿上一坐标系的 z 轴平移多少 |
| `a`     | 连杆长度 | 沿当前 x 轴平移多少         |
| `alpha` | 连杆扭角 | 绕当前 x 轴转多少           |

可以把它们理解为从坐标系 `i-1` 走到坐标系 `i` 的四步：

1. 绕 z 轴转 `theta`。
2. 沿 z 轴平移 `d`。
3. 沿 x 轴平移 `a`。
4. 绕 x 轴转 `alpha`。

这四步合起来，就能描述相邻两个连杆坐标系之间的相对位置和相对朝向。

## 5. DH 参数的四个核心量

### 5.1 theta：关节转角

如果是旋转关节，`theta` 通常就是变量。

例如机械臂肩关节转了 30 度，那么这一节的 `theta` 就可能是 30 度，再加上机械臂结构本身的固定偏置。

它回答的问题是：

> 下一段连杆绕着当前关节轴转了多少？

### 5.2 d：关节轴方向偏移

`d` 是沿 z 轴的平移。

DH 建模中，z 轴通常沿着关节轴方向放置。所以 `d` 可以理解为：

> 两个坐标系沿关节轴方向隔了多远？

如果是移动关节，`d` 通常就是变量。

### 5.3 a：连杆长度

`a` 是沿 x 轴的平移，经常对应我们直觉上的连杆长度。

它回答的问题是：

> 从一个关节轴到下一个关节轴，横向距离是多少？

在简单二维机械臂中，`a` 往往就是每段杆子的长度。

### 5.4 alpha：连杆扭角

`alpha` 是绕 x 轴的旋转。

它描述的是两个 z 轴之间的夹角，也可以理解为：

> 下一关节的转轴相对上一关节的转轴扭了多少？

在二维平面机械臂中，所有关节轴通常都互相平行，所以 `alpha` 常常是 0。但在真实 6 轴机械臂里，各个关节轴可能互相垂直或倾斜，`alpha` 就很重要。

## 6. 从 DH 参数到变换矩阵

每一组 DH 参数都会对应一个 4x4 齐次变换矩阵。标准 DH 变换矩阵通常写作：

```text
T_i =
[ cos(theta)  -sin(theta)*cos(alpha)   sin(theta)*sin(alpha)   a*cos(theta) ]
[ sin(theta)   cos(theta)*cos(alpha)  -cos(theta)*sin(alpha)   a*sin(theta) ]
[     0             sin(alpha)              cos(alpha)              d        ]
[     0                 0                       0                   1        ]
```

这个矩阵表示：

> 从第 `i-1` 个坐标系，怎么变换到第 `i` 个坐标系。

如果机械臂有多个关节，就把每一段的矩阵按顺序相乘：

```text
T_total = T_1 * T_2 * T_3 * ... * T_n
```

最后得到的 `T_total` 就是末端执行器相对于基座坐标系的位姿。

这一步是正运动学的核心。

## 7. 矩阵连乘的直观解释

可以把机械臂想象成你在地图上按导航走路：

1. 从家门口出发，先转一个角度，再向前走一段。
2. 到了路口，再转一个角度，再向前走一段。
3. 再到下一个路口，继续转，继续走。

你最终的位置，取决于每一步的转向和平移。机械臂也是一样：

- 每个关节给一个旋转。
- 每段连杆给一个平移。
- 把这些小变换按顺序串起来，就得到末端在哪里、朝向哪里。

矩阵连乘本质上就是把“每一步走法”合成“从起点到终点的一步走法”。

## 8. Python 示例说明

原文给了一个二维二连杆机械臂的正运动学示例。它做了几件事：

1. 设定两段连杆长度。
2. 设定两个关节角度。
3. 用三角函数计算第一个关节、第二个关节和末端的位置。
4. 用 Matplotlib 把机械臂画出来。

这个例子没有完整展开复杂的三维 DH 表，而是用最容易看懂的二维机械臂帮助你建立直觉。

对于二连杆平面机械臂：

```text
joint0 = (0, 0)
joint1 = (L1*cos(theta1), L1*sin(theta1))
end    = (L1*cos(theta1) + L2*cos(theta1 + theta2),
          L1*sin(theta1) + L2*sin(theta1 + theta2))
```

你可以把它理解为：

- 第一个关节决定第一段杆子指向哪里。
- 第二个关节是在第一段杆子的方向基础上继续转。
- 末端点是两段杆子的向量相加。

## 9. 正运动学与逆运动学对比

这篇主要讲正运动学，但理解它时最好顺手区分一下逆运动学。

| 问题        | 输入               | 输出           | 例子                                   |
| ----------- | ------------------ | -------------- | -------------------------------------- |
| 正运动学 FK | 关节角度/位移      | 末端位置和姿态 | 已知每个关节角度，算夹爪在哪里         |
| 逆运动学 IK | 目标末端位置和姿态 | 关节角度/位移  | 想让夹爪到杯子那里，算每个关节该怎么转 |

正运动学通常更直接，因为它沿着机械结构往前算。

逆运动学通常更难，因为同一个末端位置可能对应多种关节姿态，也可能根本到不了。

## 10. 易混淆概念

### 10.1 位置与位姿

位置只回答“在哪里”。

位姿同时回答“在哪里”和“朝哪里”。

一个机械臂末端到达同一个点，但夹爪朝上、朝下、朝左，执行效果完全不同。所以机器人任务里通常关心的是位姿，而不只是位置。

### 10.2 关节变量的类型

对于旋转关节，变量通常是 `theta`。

对于移动关节，变量通常是 `d`。

所以看 DH 表时，不要机械地认为每一行的 `theta` 都是待求关节变量，要结合关节类型看。

### 10.3 DH 表的本质

DH 参数表不是实体结构，而是对结构的抽象描述。

它的价值在于：

- 统一建模。
- 方便计算。
- 方便写程序。
- 方便在仿真和控制算法中复用。

### 10.4 坐标系建立的重要性

DH 建模最麻烦的地方往往不是矩阵乘法，而是给每个关节正确放坐标系。

一旦坐标系方向设错，参数表可能看起来很漂亮，但算出来的末端位姿会不对。

所以学习时要把重点放在：

- z 轴通常沿关节轴。
- x 轴通常沿相邻 z 轴的公法线方向。
- 每一行 DH 参数描述的是相邻两个坐标系之间的关系。

## 11. 学习理解流程

读这节内容时，可以按下面的顺序理解：

1. 机械臂由关节和连杆组成。
2. 每个关节或连杆附近都可以放一个坐标系。
3. 相邻坐标系之间的关系可以用旋转和平移描述。
4. DH 参数用 4 个数统一描述这种关系。
5. 每一行 DH 参数可以变成一个 4x4 矩阵。
6. 所有矩阵按机械臂从底座到末端的顺序相乘。
7. 最终矩阵的右上角是末端位置，左上角是末端姿态。

如果能把这条链路想清楚，就已经抓住了这节的主干。

## 12. 核心总结

如果只记几句话，可以记下面这些：

- 正运动学：已知关节状态，求末端执行器位姿。
- 末端执行器位姿：位置 + 姿态。
- DH 参数：用 `theta, d, a, alpha` 四个量描述相邻连杆坐标系之间的关系。
- 齐次变换矩阵：把旋转和位移放进同一个 4x4 矩阵。
- 矩阵连乘：把每个关节的小变换串起来，得到从基座到末端的总变换。

一句话总结：

> DH 参数是机械臂几何结构的标准化描述方式；正运动学就是根据这份描述和当前关节值，一步步算出末端执行器在空间中的位置和朝向。
